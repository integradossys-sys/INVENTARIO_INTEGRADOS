# Inventario Integrados S&S
Sistema de inventario (PHP 8 + MariaDB, JavaScript simple).

## Instalar en un servidor
1. Copia la carpeta al servidor web.
2. Copia `api/config.example.php` como `api/config.php` y pon los datos de la base de datos.
3. Importa la base de datos (el archivo .sql no está en el repositorio).

`api/config.php` no se sube a GitHub porque contiene la contraseña.
